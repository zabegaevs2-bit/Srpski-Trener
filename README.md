# Srpski Trener

Курс сербского языка от A1 до C1 для iPhone: уроки по порядку, повторение по интервалам и режим «В машине» с аудиоуроками.

## Как это устроено
- `data/course.json` — все уроки (грамматика, слова, диалоги, упражнения).
- `tools/make_audio.py` — при каждой публикации озвучивает курс нейроголосами (сербский и русский) и собирает аудиоуроки для машины.
- `.github/workflows/pages.yml` — собирает сайт и публикует на GitHub Pages.
- `js/`, `style.css`, `index.html` — само приложение. Прогресс хранится на устройстве (есть копия кодом во вкладке «Справка»).

## Публикация
1. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Запустите workflow «Build and deploy» (или сделайте любой коммит в `main`). Первая сборка озвучки занимает несколько минут.
3. Откройте адрес из Settings → Pages в Safari на iPhone → «Поделиться» → «На экран Домой».

## Как добавить урок
Добавьте объект в массив `lessons` в `data/course.json` по образцу существующих и закоммитьте. Озвучка сгенерируется сама.
